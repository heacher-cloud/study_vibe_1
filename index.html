스마트 학습지 교사 관리 & 학습 태도 분석 시스템 아키텍처 설계

학생 제출 저장 · 자동 채점 집계 · 소요 시간 및 태도 지표 분석 체계

실시간 수신 대기 중
핵심 요약

교사가 학생의 제출 내용과 태도를 확인하기 위해선
"저장소 + 태도 센서 + 채점 엔진 + 관리자 화면" 4박자가 필요합니다.

단순히 학생 화면에서만 채점하고 끝나는 구조(프론트엔드 단독)에서 벗어나, 제출 이벤트가 발생했을 때 백그라운드에서 실시간 데이터베이스(DB)로 전송하고 교사 화면에서 이를 통계화하는 파이프라인을 구축해야 합니다.

필수 1

중앙 데이터 저장소

학생들이 제출한 답안, 점수, 타임스탬프를 보관하는 데이터베이스입니다.

  • • 클라우드 NoSQL DB: 실시간 수신에 가장 적합
  • • 구글 스프레드시트 연동: Apps Script를 통해 엑셀 시트로 즉시 자동 축적
추천: Google Sheets 또는 Cloud DB
필수 2

학습 태도 센서 (Telemetry)

점수뿐 아니라 ‘어떻게 풀었는가’를 추적하는 클라이언트 측정 스크립트입니다.

  • • 순수 소요 시간: 시작 ~ 제출까지의 시간
  • • 화면 이탈 감지: 시험 중 딴짓/검색 창 전환
  • • 시뮬레이션 조작량: 지도·도구 클릭 횟수
학생 단말기에서 자동 백그라운드 기록
필수 3

자동 채점 & 성향 판별

객관식·단답형 정답 판정과 태도 점수를 종합 산출하는 로직입니다.

  • • 단답형 유연 채점: 띄어쓰기 및 유사어 처리
  • • 성향 배지 부여: "심층 탐구형", "초스피드형", "신중 검토형" 자동 라벨링
제출 즉시 1초 내에 종합 판정
필수 4

교사용 실시간 대시보드

수업 중 교탁 화면이나 스마트폰으로 학급 전체 진행 상황을 관제하는 UI입니다.

  • • 미제출자 실시간 현황 체크
  • • 오답률 1위 취약 문항 즉시 피드백
  • • 나이스(NEIS) 또는 엑셀(CSV) 다운로드
수업 중 즉각적인 개별 피드백 가능

학교 현장 적용을 위한 3가지 구축 옵션 비교

선생님의 기술 환경과 인프라에 맞춰 선택할 수 있습니다.

실시간 학생별 답안 및 참여 태도 분석표

번호 학생 정보 점수 / 등급 제출 시각 소요 시간 시뮬레이션 조작 화면 이탈 학습 태도 종합 평가 세부 답안

학습 태도 데이터(Telemetry)를 수집하는 자바스크립트 코드 원리

학생이 학습지 창을 연 순간부터 제출할 때까지 아래의 3대 센서 코드가 백그라운드에서 동작하도록 구성합니다.

1. 소요 시간 & 시험 중 딴짓(화면 이탈) 감지 
// 학습 시작 시간 기록
const startTime = Date.now();
let tabSwitchCount = 0; // 다른 창이나 탭으로 벗어난 횟수

// 학생이 다른 브라우저 탭을 열거나 유튜브/게임을 켜면 즉시 감지
document.addEventListener('visibilitychange', () => {
  if (document.hidden) {
    tabSwitchCount++;
    console.log(`[태도 경고] 학생이 학습지 화면을 벗어났습니다. 누적: ${tabSwitchCount}회`);
  }
});
2. 시뮬레이터 적극 탐구율 측정 
let mapClickCount = 0;
let rockHitCount = 0;

// 지도의 나라를 클릭하거나 도구를 직접 만질 때마다 카운트
function inspectState(stateName) {
  mapClickCount++;
  // ... 지도 정보 표출
}

function hitStone() {
  rockHitCount++;
  // ... 뗀석기 가공
}
3. 최종 제출 시 교사 서버(또는 구글 시트)로 전송하는 데이터 객체 
const payload = {
  student: { grade: "1-2", num: 15, name: "홍길동" },
  scores: { totalScore: 90, blankScore: 40, quizScore: 50 },
  answers: { ... },
  
  // ★ 학습 참여 태도 지표 데이터
  attitude: {
    startTime: new Date(startTime).toLocaleTimeString(),
    submitTime: new Date().toLocaleTimeString(),
    durationSeconds: Math.floor((Date.now() - startTime) / 1000), // 실제 소요 시간
    tabSwitches: tabSwitchCount, // 화면 이탈 횟수
    interactions: mapClickCount + rockHitCount, // 조작 적극성
    attitudeBadge: tabSwitchCount > 3 ? "주의(이탈)" : "성실참여"
  }
};

// 교사용 구글 스프레드시트 Webhook 또는 클라우드 DB로 원클릭 발송
fetch("교사용_수신_URL", {
  method: "POST",
  body: JSON.stringify(payload)
});
